📥 Import Support

  • Microsoft Visio (.vsdx) - Full shape and layout preservation
  • Draw.io (.drawio, .xml) - Complete diagram structure
  • Lucidchart (.json) - Shape and connection data
  • SVG Files - Vector graphics conversion
  • Image Files - PNG, JPG, JPEG as diagram elements
  • Generic JSON - Custom diagram formats

📤 Export Support

  • SVG - Scalable vector graphics
  • PNG - High-quality raster images
  • PDF - Document format (coming soon)
  • Draw.io - Compatible XML format
  • JSON - Native FlowDigm format
  • Visio - Microsoft format (coming soon)

🎯 Key Features

  • Bidirectional - Import and export in same formats
  • Universal Handler - Automatic format detection
  • Metadata Preservation - Maintains source information
  • Error Handling - Graceful fallbacks and validation
  • Quality Control - Configurable export options
  • Real-time Preview - See changes immediately

📚 Implementation Details

The comprehensive exportFile function includes:

  • Multiple Fallback Methods: Uses dom-to-image first, then html2canvas as fallback
  • High-Quality Rendering: 2x scale by default, customizable quality settings
  • Cross-Browser Compatibility: Handles browser-specific quirks and limitations
  • Canvas Preparation: Automatically fits view and ensures all elements are visible
  • Format-Specific Optimizations: Different strategies for each export format
  • Error Handling: Comprehensive error reporting and recovery
  • Metadata Support: Includes creation date, title, and component information
  • Library Integration: Uses html2canvas, jsPDF, PptxGenJS, docx, and dom-to-image

💡 Usage Example

// Basic usage
await exportFile('png', 'my-diagram');

// With custom options
await exportFile('pdf', 'my-diagram', {
  quality: 1.0,
  scale: 2,
  backgroundColor: '#ffffff',
  includeMetadata: true
});

// All supported formats
const formats = ['png', 'jpeg', 'svg', 'pdf', 'pptx', 'docx'];
for (const format of formats) {
  await exportFile(format, `diagram-${format}`);
}

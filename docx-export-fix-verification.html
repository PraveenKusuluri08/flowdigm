🔍 What Was Fixed

Problem: The error "className.includes is not a function" occurred because element.className can sometimes be a DOMTokenList object instead of a string in certain browsers or React components.

Solution: Added proper type checking to ensure className is always treated as a string:

// Before (causing error): const className = element.className || ''; return className.includes('react-flow__controls'); // After (fixed): const className = element.className; const classNameStr = typeof className === 'string' ? className : (className ? String(className) : ''); return classNameStr.includes('react-flow__controls');

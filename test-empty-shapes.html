📋 How to Use Your Empty Shapes:

  1. Export your diagram to get the clean DOCX file
  2. Open in Word and find the "Visual Replica" section
  3. Click below any shape to start adding your text
  4. Use Insert → Text Box to add text directly on the shapes
  5. Use Insert → Shapes to add arrows, lines, and connectors
  6. Copy/paste the shape symbols (◯ ▭) to create more elements

🎯 What You Can Do:

  • Add text anywhere - click and type below, above, or beside shapes
  • Insert text boxes - place text directly on top of shapes
  • Use Word's drawing tools - add arrows, lines, and connectors
  • Format as needed - fonts, colors, sizes, styles
  • Create your layout - arrange shapes and text however you want
  • Copy and modify - duplicate shapes to build complex diagrams
